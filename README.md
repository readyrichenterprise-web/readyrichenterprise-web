## Produk

### Parentopia — aplikasi belajar anak 0–12 tahun

Aplikasi belajar yang berjalan langsung di browser HP tanpa perlu instal (PWA): kurikulum terstruktur per fase usia, worksheet interaktif, dan progres yang tersinkron aman — dengan lisensi otomatis untuk penjualan.

| Fitur | Detail |
| --- | --- |
| **Kurikulum 4 fase usia** | Dunia belajar 0–3, 3–6, 6–9, dan 9–12 tahun |
| **Worksheet interaktif** | ±290 lembar A4 — dicoret di layar atau dicetak |
| **Multibahasa** | Narasi otomatis Indonesia, English, Mandarin, Jepang; antarmuka ID/EN |
| **Progres tersinkron** | Bintang, streak, dan riwayat kegiatan + sertifikat A4 per anak |
| **Untuk keluarga** | Multi-profil anak per akun, laporan bulanan PDF untuk orang tua |
| **Penjualan otomatis** | Lisensi terkirim via WhatsApp setelah pembayaran (integrasi Scalev) |
| **Keamanan** | Materi terkunci per sesi pembeli; lisensi mati otomatis saat refund |

Tautan: [parentopia-ready-rich-enterprise.vercel.app](https://parentopia-ready-rich-enterprise.vercel.app)
