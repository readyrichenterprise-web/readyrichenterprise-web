# ReadyRich Enterprise

Perusahaan produk digital untuk keluarga Indonesia — aplikasi edukasi anak yang rapi, aman, dan mudah dipakai orang tua maupun anak.

## 🚀 Produk

### [Parentopia](https://parentopia-ready-rich-enterprise.vercel.app)

Aplikasi belajar anak 0–12 tahun — berjalan di browser HP tanpa perlu instal (PWA).

**Fitur utama**

- 🎓 Empat dunia belajar per fase usia: 0–3, 3–6, 6–9, dan 9–12 tahun
- ✏️ ±290 worksheet A4 interaktif — bisa dicoret di layar atau dicetak
- 🔊 Narasi otomatis 4 bahasa: Indonesia, English, Mandarin, Jepang
- 📈 Progres, bintang, dan streak tersinkron antar perangkat + sertifikat A4
- 👨‍👩‍👧 Multi-profil anak per akun, laporan bulanan PDF untuk orang tua
- 🛒 Lisensi otomatis terkirim via WhatsApp setelah pembayaran (integrasi Scalev)
- 🔐 Materi terkunci per sesi pembeli; lisensi mati otomatis saat refund

## 🧰 Teknologi

`JavaScript` · `Node.js` · `Vercel` · `PostgreSQL (Neon)` · `PWA` · `WhatsApp Bridge` · `i18n ID/EN`
